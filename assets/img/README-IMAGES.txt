  RAEM — REPLACE THESE WITH YOUR OWN PRODUCT PHOTOS
=========================================================

  طريقة الاستبدال:
  1) صوري بعباياتك الحقيقية.
  2) سمّي كل ملف بالاسم المذكور بالضبط (بدون مسافات).
  3) استبدلي الملف داخل assets/img/products/ مباشرة.
  4) لا حاجة لتعديل أي كود — الأسماء مربوطة داخل script.js.

  How to replace:
  1) Shoot your real abayas.
  2) Rename each file exactly as listed (no spaces).
  3) Overwrite the file inside assets/img/products/ .
  4) No code changes needed — names are already wired in script.js.

  مواصفات الصورة المقترحة:
  - الصيغة: JPG أو WEBP.
  - النسبة: عمودية 3:4 (مثال 1200x1600) — الصورة تُقصّ تلقائيًا 3:4.
  - الحجم: حتى 400 كيلوبايت للصورة الواحدة يكفي.
  - سمّي صورك بنفس أسماء الملفات بالضبط وإلا لن تظهر.

  ملاحظة: كل الصور الحالية محلية داخل الموقع (لا روابط خارجية)،
  لذلك الموقع يعمل بشكل كامل بدون إنترنت وبسرعة عالية.
