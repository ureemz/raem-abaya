## نظرة عامة | Overview

أربع صفحات مستقلة، تنشارك `style.css` و`script.js`:

| الصفحة | الملف | الوظيفة |
|---|---|---|
| الرئيسية | `index.html` | البطل، القطع المميزة (٦ قطع)، شرائح الألوان، مساحة التحرير |
| المجموعة | `collection.html` | كل القطع (٢٤) مع فلترة حسب اللون / السعر / نوع التصميم |
| عن البراند | `about.html` | القصة، القيم، موزاييك صور، معلومات المتجر |
| تواصل | `contact.html` | نموذج تواصل (تجريبي) + روابط واتساب وإنستقرام |

- اللغة: عربية بالكامل — `lang="ar"` و`dir="rtl"` في كل صفحة
- التصميم: CSS منطقي بالكامل (`inline-start` / `inline-end`) — يشتغل RTL/LTR بنفس الملف
- الخطوط: **Bodoni Moda** (اللوجو والعناوين الإنجليزية) + **Tajawal** (العربي) من Google Fonts
- بدون أي مكتبات خارجية، بدون jQuery، بدون build step
- متجاوب من ٣٢٠px حتى الشاشات العريضة

## من أين أحرّر؟ | Where to edit

**كل البيانات القابلة للتعديل في مكان واحد: أعلى `script.js`.**
ما تحتاج تلمس HTML ولا CSS لتعدّل المنتجات أو الأسعار أو الألوان أو التصنيفات.

### ١) `RAEM_CONFIG` — إعدادات المتجر

```js
const RAEM_CONFIG = {
  brand: "RAËM",
  whatsapp: "0542308267",       // الرقم المحلي — يُحوَّل تلقائيًا إلى wa.me
  whatsappDisplay: "+966 54 230 8267",
  instagram: "instagram.com/raem.abayas",
  email: "hello@raem.sa",
  city: "الرياض، السعودية",
  ...
};
```

### ٢) `RAEM_COLORS` — الألوان (٥ ألوان)

كل لون: `key` (الاسم في الرابط) · `name` (العربي) · `tagline` · `swatch` · `image` · `alt`.
شريحة اللون في الصفحة الرئيسية **تُبنى تلقائيًا** من هذه المصفوفة.

### ٣) `RAEM_DESIGNS` — أنواع التصميم (٦ تصنيفات)

### ٤) `PRODUCTS` — القطع (٢٤ قطعة)

```js
{
  id: "salma",
  name: "عباية سلمى",
  color: "أسود",              // يظهر كما هو في رسالة الواتساب
  colorKey: "black",
  design: "دانتاز",            // يظهر كما هو في رسالة الواتساب
  price: 549,
  image: "assets/img/products/lace-collar-black.jpg",
  featured: true,
  source: "https://www.pinterest.com/pin/…"   // للقطع العشر الأولى فقط
}
```

- `price` — السعر بالريال، يظهر في البطاقة وفي السلة ورسالة الواتساب
- `featured: true` — القطعة تظهر في «قطع مميزة» بالصفحة الرئيسية (٦ قطع)
- `color` / `design` — **نص عربي يظهر حرفيًا** في رسالة طلب الواتساب
- `source` — رابط البِن الأصلية من Pinterest (للمرجع فقط)

> **الفلاتر تُبنى تلقائيًا:** شرائح الألوان والتصميمات في `collection.html`
> تُولَّد في JS من `PRODUCTS` — فما تحتاج تعدّل أي فلتر في HTML يدويًا.
> لو حذفتِ قطعة أو غيّرتِ لونها، الفلتر يتحدّث لحاله.

### نطاق السعر

السعر الأعلى في الموقع (`PRICE_MAX`) **يُقرأ من** شريط السعر في `collection.html`:

```html
<input type="range" id="priceRange" min="400" max="700" step="10" value="700">
```

عدّلي `max` هناك، ويتحدّث كل شيء تلقائيًا.

### روابط المنتجات (Deep links)

`collection.html?color=black` · `?color=mocca` · `?color=grey` · `?color=taupe` · `?color=ivory`

## كيف أستبدل الصور؟ | Swapping images

كل الصور محلية في `assets/img/products/` — لا يوجد روابط خارجية (سريع + يشتغل بدون إنترنت).

خريطة الاستبدال الكاملة في **`assets/img/README-IMAGES.txt`** — فيها اسم كل ملف ومكان استعماله.
القاعدة: **اسم الملف نفسه = اسم المنتج**، فاستبدلي الملف بالصورة الجديدة والموقع يتحدّث لحاله.

ملاحظات:
- `lace-collar-black.jpg` يخدم **البطل** في الصفحة الرئيسية **و**قطعة «سلمى» في الكاتالوج
- المقاس المفضّل: عمودي 1080×1920 (9:16) للقطعة الواحدة
- بعد الاستبدال: حدّثي `alt` داخل `script.js` و`index.html`

## ملاحظات مهمة | Important notes

1. **السلة تجريبية** — درج «السلة» للعرض فقط، ما فيه خادم ولا تخزين للطلبات.
   الطلب الفعلي يتم عبر **واتساب** برسالة جاهزة فيها اسم القطعة والسعر واللون والتصميم.
2. **آراء العملاء تجريبية** — النصوص المكتوبة في `about.html` موسومة بـ
   «نص تجريبي — قابل للاستبدال». استبدليها بآراء حقيقية قبل الإطلاق.
3. **معلومات المتجر ناقصة** — أي معلومة غير مؤكدة (الموقع، ساعات العمل، رقم السجل…)
   مكتوبة **«يُضاف عند الاعتماد»**. لا تُنشر قبل تعبئتها.
4. **الصور الحالية من Pinterest** — هي صور مؤقتة للعرض فقط،应当在 استبدالها
   بصور المتجر الحقيقية قبل الإطلاق للتوافق مع نظام royalty.
5. **الأسعار** — النطاق الظاهر في الموقع 400–700 ريال، وأسعار القطع الفعلية 450–690 ريال.
6. **فريق التطوير** — البنية جاهزة لصفحات/قطع جديدة: أضيفي عنصرًا في `PRODUCTS` فقط.
